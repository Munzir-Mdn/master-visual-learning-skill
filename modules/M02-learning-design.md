# Learning Design (MVLS V1.0)

## Objective
Adapt explanation to Beginner, Intermediate or Advanced. Explain core concept, relevant relationships and concise examples. Preserve official terminology, code and CLI commands. Basic visual explanation only by default: no automatic quizzes, Feynman, Active Recall or Mastery Learning. Split complex topics logically; obey language and density overrides.

## Handoff
Provide concise decisions, validation flags and constraints to the next module. Record what was actually checked, not assumed.
