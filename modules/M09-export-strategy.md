# Export Strategy (MVLS V1.0)

## Objective
Honor user-selected format; otherwise choose based on purpose and available tools. Candidate formats: PDF, PNG, SVG, PPTX, HTML, Markdown, DOCX. Confirm actual tool availability and successful creation; verify file exists, opens or parses, and where possible inspect rendering. If requested format unavailable, disclose and offer supported fallback. Preserve editable source where feasible. Never create files without authorization.

## Handoff
Provide concise decisions, validation flags and constraints to the next module. Record what was actually checked, not assumed.
