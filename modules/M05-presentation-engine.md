# Presentation Engine (MVLS V1.0)

## Objective
Choose narrative based on academic, technical, briefing or storytelling purpose. Build a logical outline; favor one central message per slide where practical. Use modular title, evidence, comparison, process, diagram and conclusion layouts. Add progressive reveal only when it aids comprehension and the format supports it; retain a static fallback.

## Handoff
Provide concise decisions, validation flags and constraints to the next module. Record what was actually checked, not assumed.
