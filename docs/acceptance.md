# Acceptance Criteria

## Universal gates
- [ ] Requested content, language, audience and format respected.
- [ ] Explicit approval exists before creating files/code or installing anything.
- [ ] Critical information preserved; no fabricated claims or sources.
- [ ] Technical terms and notation are consistent.
- [ ] No mandatory quizzes/Feynman/Active Recall inserted.
- [ ] Sources summarized at end with legally/academically necessary exceptions.
- [ ] Layout and text are readable; no known clipping or overlaps.
- [ ] Risk tier identified; technical and mathematical claims checked proportionately.
- [ ] Requested output exists and is verified when files are claimed.
- [ ] Limitations and unchecked items clearly labeled.

## Risk-based acceptance
Low: semantic review + basic layout. Medium: add targeted diagram/terminology checks. High: independent calculation or domain checks, source scrutiny and rendering review if tools exist.

## Result
PASS only when all applicable critical checks pass. REVISION REQUIRED for known critical failures. NOT VERIFIED when required tools or source evidence are missing. Never substitute a checklist for actual inspection.
