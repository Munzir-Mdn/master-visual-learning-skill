# Usage Guide

## Example request
"Use MVLS to produce beginner-friendly Malay visual notes for OSI Model from my uploaded slides, preserving English technical terms. Output a two-page PDF with an accurate 7-layer diagram. You are authorized to create the PDF and necessary supporting files."

## Revision request
"Correct the TCP/IP mapping only; preserve all approved sections and record a version change."

## Important
This package is a portable agent instruction skill, not an autonomous app. It relies on the host assistant's document readers, renderers and exporters. The agent must not claim capabilities it does not have. To install in a particular skill host, follow that host's supported import procedure; no universal installer is provided.
